# 机关图片 · 绘本工坊

这批素材使用内置 image_gen 逐件生成，原始透明 PNG 保存到项目的 `assets/props/`。完整的实际生成提示词在 [art-prompts.json](art-prompts.json)。

共同方向：奶油瓷、鼠尾草绿搪瓷、粉红陶瓷、旧黄铜和蜂蜜木色；柔和水粉笔触；正面独立物件；小尺寸下仍能认出用途。保持透明背景，场景、文字、亮灯、连线及状态由游戏实时绘制。

| 文件 | 游戏用途 |
|---|---|
| `paw.png` | 狗操作的粉色爪印机关 |
| `plate.png` | 刺猬滚压、站立或重压的铜踏板 |
| `door.png` | 随机关升降的木门 |
| `fan.png` | 开关控制的风扇，配合动态风向线 |
| `pump.png` | 补充房间总气量的手动气泵 |
| `lamp.png` | 高处作业灯与热灯 |
| `fridge.png` | 冷气与结冰机关 |
| `cage.png` | 藏有气球锁的鸟笼 |
| `apple.png` | 刺猬收集、堆叠的苹果座位 |
| `cat.png` | 声音机关中的睡猫 |

只读取图片的透明范围以确定绘制边界，不改写生成的像素。尖刺、风区、冷热范围和绳索仍与真实判定同步绘制。所有原关卡、机关规则和历史版本保留。
